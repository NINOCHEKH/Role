# Дитя Луны

Роман по совместной ролевой истории. Чехерия Нино & Суга.

## Файлы

- `index.html` — разметка и текст всех глав
- `style.css` — оформление
- `script.js` — затмение и звёзды на обложке, открытие книги, переключение глав, размер шрифта, тема

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него эти файлы.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.
